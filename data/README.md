# Dataset

The COVID-19 dataset used in this project contains global information related to COVID-19 cases, deaths, healthcare capacity, population, GDP, and policy-related indicators.

## Data Source

The dataset was used for educational and portfolio purposes as part of my data analytics learning journey.

## Data Preparation

The data was explored and analyzed using SQL before creating visualizations and the final dashboard in Tableau.

## Important Note

This project is intended for learning and portfolio purposes. The analysis represents my interpretation of the available dataset and does not represent official public health conclusions.
